## 2. 小白裝機教學（約 4 分鐘）

**標題**
第一次組電腦就上手！CPU、記憶體、顯卡、電源 9 步驟圖解｜小白裝機教學

**說明**
```
想自己組電腦，但看到一堆零件就頭昏？
這支影片用立體動畫，一步一步帶你從零件到開機：
✅ 認識零件：主機板、CPU、散熱器、記憶體、M.2、顯示卡、電源供應器
✅ 開工前：拔電源線、放靜電
✅ STEP 1–4：裝 CPU（對準金色三角形）、散熱膏和散熱器、記憶體雙通道、M.2 30° 斜插
✅ STEP 5–8：主機板入殼（銅柱）、電源 24-pin／8-pin、顯示卡插 PCIe、接前面板線
✅ STEP 9：開機測試、進 BIOS、開 XMP／EXPO

裝機順序：CPU → 散熱 → 記憶體 → 硬碟 → 入殼 → 電源 → 顯卡 → 接線 → 開機
※ 各品牌主機板配置不同，實際安裝請對照說明書。
```
