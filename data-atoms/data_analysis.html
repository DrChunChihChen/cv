Phase 01

拿到資料：鎖定權威資料庫與 API 連線

role: data ingestion

分析的第一步不是下載 CSV，而是定義商業命題，並透過 API 連線取得官方權威數據。今天我們串接日本總務省統計局 e-Stat 官方 API，鎖定 1975 到 2024 半世紀 47 都道府縣面板數據。

  • 在個人 My Page 申請金鑰（appId）。
  • 避坑重點：登錄 URL 務必填寫 http://test.localhost。
  • 調用端點：/getStatsList 取得目錄；/getStatsData 獲取數據。
terminal: fetch_estat.py REST v3.0
$ python3 scripts/fetch_estat_showcase.py
[e-Stat] Connecting to api.e-stat.go.jp...
[e-Stat] Table: 0000010101 (SSDSE-A-2024)
[e-Stat] Loaded 47 prefectures x 50 years.
✓ Saved raw JSON: 14,800 records.
Phase 02

處理資料：調用 data-analyst 技能自動清洗

專屬 Skill 封裝
調用 data-analyst 輕量技能包 GitHub 倉庫 ↗

Phase 03

探索性驗證 (EDA)：尋找異常與極值
