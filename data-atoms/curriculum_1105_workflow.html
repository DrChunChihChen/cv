課程兩大階段核心技術解構

hands-on modules breakdown
第一塊：認知篇 (15%)

大語言模型學習地圖 (index.html)

以原版《大語言模型學習地圖》為核心，引導學員建立底層世界觀與 Agent 概念：

  • 通關 6 大站點：理解與生成、交代任務、查資料記憶、Tool Calling、Workflow、Evals 核對。
  • 全球競爭格局：全球主流開源與商用大模型全景（Claude 3.5, GPT-4o, Gemini 2.0, DeepSeek）。
  • 為什麼需要 Agent 工具：理解純語言模型在即時資料與精確計算上的極限，引出調用外部工具與 API 的必要性。
第二塊：工具與 API (85%)

使用哪套工具？串接哪一些 API？

真實工程環境與權威資料庫，拒絕假數據與空泛玩具代碼：

  • 工具 1：Antigravity（Google DeepMind 開發之 Agentic Coding 環境，自主執行終端與 Skill 擴展）。
  • 工具 2：前端開源引擎（Apache ECharts 互動圖表與 Graphic Walker 拖曳編碼槽，Zero-Build 即開即用）。
  • API：日本 e-Stat 官方 REST API v3.0（總務省統計局官方資料庫）。
  • 端點呼叫：/getStatsList 取得 17 大領域代碼；/getStatsData 獲取半世紀面板數據。
第二塊：Skill 與成果交付

用了哪些 Skill？做出什麼成果？

將複雜的資料處理、網頁版面與美學工程封裝為 8 大 Skill，附 GitHub 開源倉庫供學員探索：

  • data-analyst（示範）：分析師 Prompt 提示詞樣板與 clean_data.py 清洗腳本（GitHub ↗）。
  • hallmark（網頁設計）：現代工程極簡網頁規範與 dose 藥盤主題（GitHub ↗）。
  • diagram-design（架構流程）：繪製分析師 5 階段流程圖與全日時序圖 SVG（GitHub ↗）。
  • dataviz（圖表規範）：Tufte 工業級視覺化美學與 WCAG AA 對比度（GitHub ↗）。
  • dataviz-motion（動態影音）：將分析圖表轉化為 1080p 60FPS 包豪斯動態簡報（GitHub ↗）。
  • data-atoms-dashboard（儀表板）：一鍵產出 10 大數據原子、Tableau Prep 分類（開源 ↗）。
  • deeptutor-mentor（自主學習）：港大 DeepTutor 架構，無老師也能靠三階提示獨立自學（GitHub ↗）。
