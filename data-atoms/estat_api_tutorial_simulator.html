step 03 / 避坑核心
URL 嚴格規範

官方防禦機制嚴格禁止純 localhost！請務必填寫 http://test.localhost 即可直接通過驗證。

step 04 / 取得金鑰
點擊 Issue 發行

點擊右側 Issue 按鈕，系統立即生成 40 碼專屬金鑰（appId），後續呼叫 REST API 即可代入。

python: fetch_estat_api.py REST v3.0
import requests

app_id = "YOUR_40_CHAR_APP_ID"
url = "https://api.e-stat.go.jp/rest/3.0/app/json/getStatsData"
params = {
    "appId": app_id,
    "statsDataId": "0000010101", # SSDSE-A 47都道府縣社會人口大表
    "metaGetFlg": "Y"
}
response = requests.get(url, params=params)
data = response.json()
print(f"獲取成功，共載入 {len(data['GET_STATS_DATA']['STATISTICAL_DATA']['DATA_INF']['VALUE'])} 筆紀錄")
endpoint: api.e-stat.go.jp/rest/3.0/app / status: operational
